# 🤖 Noura Chat – المساعد الذكي لمتجر TechZone تيك زون

شات بوت ذكي يعمل كمساعد خدمة عملاء لمتجر **TechZone تيك زون** الإلكتروني المتخصص في المنتجات التقنية في اليمن.

يجمع بين **نظام الردود القاعدية (Rule-Based)** و**نموذج GPT-4o-mini من OpenAI** لتقديم تجربة محادثة طبيعية وذكية باللغة العربية.

---

## 🎯 فكرة المشروع

بناء شات بوت ذكي لخدمة عملاء متجر إلكتروني يمني، يستطيع:
- **الرد الفوري** على الأسئلة الشائعة بدون الحاجة لاستدعاء AI
- **الرد الذكي** على الأسئلة المعقدة باستخدام GPT-4o-mini
- **التعامل باللهجة اليمنية والعربية** بشكل طبيعي
- توفير تجربة مستخدم سلسة عبر واجهة ويب أنيقة

## ⚙️ كيف يعمل النظام

### 1️⃣ نظام كشف النية (Intent Detection) – Rule-Based

عند استقبال رسالة من المستخدم، يمر النظام بالخطوات التالية:

```
رسالة المستخدم → تنظيف النص → مطابقة الكلمات المفتاحية → رد فوري
```

- يتم **تنظيف النص** من علامات الترقيم والمسافات الزائدة
- يتم **مطابقة الكلمات المفتاحية** مع 25+ نية محددة مسبقاً
- إذا تم العثور على تطابق → **رد فوري بدون استدعاء AI**

### 2️⃣ النموذج الذكي (GPT-4o-mini) – Fallback

إذا لم يجد النظام رداً مناسباً من القواعد:

```
رسالة المستخدم → System Prompt + سياق المتجر → GPT-4o-mini → رد ذكي
```

- يتم إرسال الرسالة مع **System Prompt** يحتوي على جميع سياسات المتجر
- النموذج يرد بأسلوب ودود ومهني باللغة العربية
- **الحد الأقصى:** 200 توكن للرد الواحد

## 🚀 تشغيل المشروع محلياً

### المتطلبات
- Python 3.9+
- مفتاح OpenAI API

### خطوات التشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/jabreel500/noura-chat-api.git
cd noura-chat-api

# 2. تثبيت المكتبات
pip install -r requirements.txt

# 3. إنشاء ملف .env وإضافة مفتاح API
echo OPENAI_API_KEY=your_api_key_here > .env

# 4. تشغيل الخادم
uvicorn app:app --reload --port 8000
```

ثم افتح ملف `index.html` في المتصفح.

### API Endpoint

```
POST /chat
Content-Type: application/json

{
  "message": "مرحبا"
}
```

**الرد:**
```json
{
  "answer": "أهلاً وسهلاً بك في TechZone تيك زون! 👋\nأنا مساعدك الذكي، كيف يمكنني خدمتك اليوم؟",
  "source": "rule"
}
```

- `source: "rule"` → الرد من النظام القاعدي
- `source: "llm"` → الرد من GPT-4o-mini
